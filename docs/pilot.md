# Opt-in pilot

This page is for an independent maintainer. Open a report only after you
finish a real task. Nobody sends a first message. There is no cold outreach.

## What to run

Use the [behavior quickstart](quickstart-behavior.md). It shows a broken
function, a refused close, a repair, and a rerun.

Then use showwork on one real task in your own repository. `finish` must
refuse one failure that you caused on purpose.

## What counts

An activation needs all of these:

- You are not the showwork owner, a bot, or a staged demo.
- You finish a real task receipt in your repository.
- You show one intentional failure that `finish` refuses.
- You name the repository, or you give permission for redacted proof.

A repeat use is the same project on another real task at least 7 days later.

The target before 2026-10-13 is 3 activations and 2 repeat users. A zero
count is a valid result. These targets are not a promotion claim.

Open a [Pilot report](https://github.com/bmdhodl/showwork/issues/new?template=pilot-report.yml).
