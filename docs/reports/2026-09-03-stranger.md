## What a stranger can do now that they could not before

1. Paste the README Quickstart into an empty directory. The first `finish --status ok` exits 2. The file was never written. That is the product. Recovery is in the same README: write the file, retract, re-claim, finish GREEN.
2. Run `python -m showwork` after `pip install`. There is a `__main__` module. Empty argv prints help and exits 0.
3. Run `showwork init` in their own repo. That writes a Cursor rule, a Claude Stop hook, and `docs/ci/showwork-verify.yml`. It does not write `.github/workflows/`.
4. Load a Cursor rule that tells the agent to start, claim, and finish. Walk: `docs/walks/cursor.md`.
5. Pass `--showwork-session` to pytest to record a passing-run claim. Without the flag the plugin is silent.
6. Hit RED when they delete or edit a file that existed at `session.start` and no claim named that path. That is issue #64. Old ledgers without `tree_snapshot` skip the check.

They still cannot `pip install` this tree until Patrick publishes 0.4.0. PyPI serves 0.3.0. The README states that gap.
