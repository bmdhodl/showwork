## Definitions

An activation is an outside user who finishes a real task receipt and shows
an intentional failure that `finish` refuses. The report names the repository
or gives permission for redacted proof.

A repeat use is the same independent project on another real task at least
7 days later.

Owner accounts, bots, and staged demos are excluded.
